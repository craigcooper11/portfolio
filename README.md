# portfolio

Personal portfolio site for Craig Cooper — Senior Agentic AI Lead & Software
Development Manager.

Single static file (`index.html`), Tailwind via CDN, no build step. Deployed
with GitHub Pages from `main` / root.

Local preview: `python3 -m http.server` from the repo root, then open
<http://localhost:8000>.

See `claude.md` for context aimed at AI coding agents working on this repo.
